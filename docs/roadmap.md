# Roadmap

pytest-deck is in beta. The core promise (a deck run matches a real
command-line pytest run) is shipped and stable; what remains is breadth and
polish. Directions for the releases ahead:

- **More plugin switches out of the box**, growing the set of integrations that
  work with zero setup.
- **Richer panels** for the plugins the deck already knows, building on the
  coverage, benchmark, and attachments views.
- **Screenshots and visual docs**, so the UI pages show the dashboard instead
  of describing it.
- **Beta feedback first.** Real-world use decides the priorities between here
  and 1.0.

If something's missing or broken for your suite, please
[open an issue](https://github.com/mchalela/pytest-deck/issues). Beta feedback
is exactly what this phase is for.
